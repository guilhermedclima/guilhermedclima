### 🦅 AlertHawk — Open Source Infrastructure Monitoring

[![AlertHawk](https://img.shields.io/badge/🌐_alerthawk.net-Live-00C851?style=for-the-badge)](https://alerthawk.net)
[![GitHub](https://img.shields.io/badge/GitHub-AlertHawk-181717?style=for-the-badge&logo=github)](https://github.com/alertmanagehq)

A **horizontal scalable** monitoring platform built with modern technologies:
**.NET 9 · React · Microservices · Kubernetes · RabbitMQ · Redis · MassTransit**

✅ Real-time Kubernetes metrics (cluster, pods, resources)
✅ Alerts via Slack, Microsoft Teams, Email & Webhooks
✅ On-premise deployment with full Docker/K8s support
✅ Free & Open Source
